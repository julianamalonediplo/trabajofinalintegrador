
# Artuli — Ecosistema digital para la enseñanza y aprendizaje del inglés

## Descripción del proyecto

Artuli es una propuesta educativa orientada a la enseñanza del inglés mediante experiencias lúdicas, creativas y significativas.

Este proyecto busca integrar herramientas digitales, inteligencia artificial generativa y automatización de procesos para facilitar el trabajo docente y ampliar el acceso a recursos educativos. Asimismo, a través de esta página web se busca centralizar la información de Artuli para ambos públicos:
- Familias: un lugar donde puedan encontrar información sobre qué es el taller de Artuli, su metodología, saber dónde contactarse (por Instagram o WhatsApp) y tener acceso a material educativo para aprender o practicar inglés en familia.
- Docentes de inglés: una sección con información clara sobre un espacio para teachers, para generar una comunidad, donde se comparte la metodología Artuli: recursos gratuitos, actividades generadas con el enfoque del taller, recursos para comercialización y futuras capacitaciones.

## Objetivos

- Centralizar la información para docentes y familias, las herramientas y los recursos de Artuli en una página web.
- Automatizar la solicitud y el envío de recursos gratuitos.
- Generar actividades de inglés personalizadas mediante inteligencia artificial.
- Desarrollar productos educativos digitales y planificar su comercialización.

## Componentes del proyecto

### 1. Página web
Desarrollada con HTML, CSS y JavaScript. Centraliza las propuestas y herramientas de Artuli.

### 2. Recursos gratuitos para docentes
Sistema desarrollado con Google Forms, Google Sheets, Google Drive, Gmail y Google Apps Script para gestionar solicitudes y enviar materiales educativos.

### 3. Generador de actividades con IA
Herramienta que utiliza Google Apps Script y Gemini para generar actividades de inglés según parámetros pedagógicos definidos por el docente.

### 4. Ebooks educativos
Sección incorporada a la web. El ebook para docentes está en etapa final de elaboración. Se prevé desarrollar posteriormente un ebook para familias y automatizar la comercialización mediante Systeme.io.

## Herramientas utilizadas

- HTML, CSS y JavaScript
- GitHub
- Google Apps Script
- Google Forms, Google Sheets, Google Drive y Gmail
- Gemini
- ChatGPT
- Systeme.io (integración comercial planificada)

## Estado del proyecto

Las automatizaciones de recursos gratuitos y el generador de actividades se encuentran operativos según las pruebas realizadas durante el desarrollo.

La sección de ebooks está creada. La automatización de ventas y entrega mediante Systeme.io todavía está pendiente.
